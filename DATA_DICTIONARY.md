# Partnerships and Media References Dataset — Data Dictionary This file defines the fields used in `partnerships-and-media-references.jsonl` and `partnerships-and-media-references.csv`. | Field | Description | |---|---| | `record_id` | Stable record identifier. | | `record_type` | Normalized record category. | | `sequence` | Record sequence number from the source extraction. | | `section_id` | Top-level section identifier from the source extraction. | | `section_title` | Plain-English section title. | | `subsection_title` | Plain-English subsection title, when available. | | `title` | Display title for the record. | | `year_start` | Detected year or range start, when available. | | `year_end` | Detected year or range end, when available. | | `urls` | Array of URLs extracted from the source record. | | `primary_url` | First extracted URL, when available. | | `primary_domain` | Domain parsed from the primary URL. | | `tags` | Normalized source tags retained from the extraction. | | `summary` | Cleaned one-line summary for search and retrieval. | | `source_text` | Cleaned source block text retained for review. | | `content_hash` | Hash retained from source extraction when available. | | `source_document` | Source document label. | | `source_line_start` | Start line in the source document, when available. | | `source_line_end` | End line in the source document, when available. | | `dataset` | Current dataset slug. | | `license` | Dataset license. | | `interpretation_note` | Cautionary note about record interpretation. | ## Notes The dataset preserves structured source records while removing legacy directive-style framing and older internal naming. Use `record_type`, `title`, `summary`, `urls`, and `source_text` for retrieval and review. Records are self-published archive records and should be evaluated with source context.
